Every fact on this site is now stored as data instead of as a page layout. A
sponsor is one file. A robot is one file. The sponsor wall builds itself from
those files, which means adding a sponsor no longer requires anyone to open a
page editor.

If you can edit a text file on GitHub, you can update this site. See
CONTRIBUTING.md.
